### 핵심 인사이트

1. **의례성 강한 행사일수록 6단 구조 정형성 ↑**
   - 추모사·시정연설·간담회·위촉식: 80% 이상

2. **자유 형식 행사는 별도 처리 필요**
   - 서면축사·발간사: 60% 이하
   - 공동언론발표: 외교 형식 별도

3. **「서면축사」는 4단 별도 구조 필수**
   - 가장 큰 발견. 50건 중 일치율 33%로 최하위 사례가 「[서면축사] 경기도 주택공급」
   - 정책 보고서 형식이라 6단 구조 미적용

## 데이터 활용 방식

### 학습 데이터로 활용 (Few-shot)

L2 도메인 지식 Layer에 우수 사례 3~5건을 Few-shot 예시로 포함:

```python
EXAMPLES = [
    {
        'input': {
            'event_type': '기념사',
            'event_name': '제○회 ○○의 날',
            ...
        },
        'output': {
            'draft': '...'  # speech.xml 우수 사례 본문
        }
    },
    # ...
]
```

### 평가 데이터로 활용

생성된 초안의 6단 구조 일치도를 50건 분석 결과와 비교하여 품질 측정.

### 통계 추출용으로 활용

청중별·분량별·행사 유형별 통계 자동 추출:
- 평균 단락 수
- 평균 단락 길이
- 정형구 사용 빈도
- 한자어 비율

## 데이터 보안·프라이버시

- 모든 데이터는 **공공데이터** (정책브리핑 공공누리)
- 사용자 업로드 자료는 AI 분석 후 **즉시 삭제**, 추출 텍스트만 세션 내 보관
- 민감정보는 정규표현식 기반 자동 마스킹
- 다중 자료 업로드 시 자료 간 격리 처리
