# 말씀자료 AI 작성기 (가칭: 부처 콘텐츠 작성 통합 플랫폼)

## 한 줄 요약

행정안전부 등 정부 부처 실무자가 **5분 안에 행사용 말씀자료(축사·기념사 등) 초안을 작성**할 수 있도록 돕는 AI 도구. Phase 2에서 보도자료 모듈을 추가하여 부처 콘텐츠 작성 통합 플랫폼으로 확장.

## 프로젝트 위상

- **현재**: 빅보스님 개인 사이드 프로젝트 (진료후 패턴)
- **목표**: 부서(기반국 또는 디지털정부국) 내 파일럿 → 행안부 확산 → 범정부 확장
- **사용자**: 1차 = 빅보스님 부서 동료 5~10명, 확장 = 행안부 전체 → 타 부처

## 풀고자 하는 문제

현재 부처 실무자는 행사 말씀자료를 작성할 때 다음 중 하나의 방식을 사용:
1. 처음부터 직접 작성 (시간 소요 큼)
2. 과거 유사 행사 자료 복사·수정 (정합성 떨어짐)
3. ChatGPT 등 일반 LLM 사용 (부처 톤 안 맞음, 보안 우려)

→ **부처 특유의 6단 정형 구조와 행사 유형별 차이를 학습한 AI 도구**가 필요.

## 핵심 가치 제안

| 기존 방식 | 본 도구 |
|---|---|
| 백지에서 시작 (30분~1시간) | 5분 내 완성된 초안 |
| 일반 LLM (부처 톤 안 맞음) | 50건 부처 자료 학습한 정형 구조 |
| 행사 정보 직접 입력 | 행사계획서 업로드 → 자동 추출 |
| 분량 조절 어려움 | 5단계 분량 + 사용자 지정 |
| 톤 일관성 부족 | 페르소나 + 가드레일 검증 |

## MVP 범위 (Phase 1)

**포함**:
- 8가지 행사 유형 지원 (축사·기념사·신년사·격려사·환영사·개회사·이임사·서면축사)
- 행사계획서 업로드 → 자동 추출 (HWPX/DOCX/PDF/이미지)
- 참고자료 다중 업로드 → 본문 RAG 컨텍스트
- 5단계 분량 + 사용자 지정
- AI 초안 생성 (5-Layer 프롬프트 + 가드레일 자동 검증)
- 편집 + **MD 출력** + 클립보드 복사

**제외 (MVP 후 추가)**:
- HWPX 출력 (v2.0에서 PoC 후 결정)
- 회의 모두발언 행사 유형 (검증 표본 부족)
- 외교 공동언론발표문 (별도 구조 필요)
- 페르소나 정밀 학습 (빅보스님 부서 자체 자료 학습)
- 보도자료 모듈 (Phase 2)

## 검증 결과 요약

- **데이터**: 정책브리핑 RSS 50건 (1,232단락)
- **일치율**: 79.0% (두 가지 태깅 방식 비교)
- **결론**: 의례성 강한 행사(추모사·시정연설)는 80%+, 자유 형식(서면축사)은 60~70% → 행사 유형별 분기 필요
