## 화면 2-B-1 (행사계획서 업로드)

### 입력
- 파일 1개 (HWPX/DOCX/PDF/이미지)
- 최대 20MB

### 처리 흐름
```
업로드 → 형식 검증 → 텍스트 추출 → 민감정보 마스킹
→ AI 정보 추출 (행사명·일시·참석자 등) → 신뢰도 평가
→ 폼 자동 채움 + 본문 컨텍스트 보존
```

### 출력
- 화면 2-B 폼 자동 채움
- 본문 전체가 RAG 컨텍스트로 보존되어 AI 작성 시 참고

## 화면 2-B-2 (참고자료 다중 업로드)

### 입력
- 다중 파일 (HWPX/DOCX/PDF/TXT/이미지)
- 최대 10개, 파일당 20MB

### 자료 자동 분류 5종

| 분류 | AI 활용 방식 | 우선순위 |
|---|---|---|
| 정책 추진계획서 | 4단 정책 사례에 직접 반영 | 1순위 |
| 통계·인용 자료 | 4·5단 인용구 + 사용자 선택 체크리스트 | 2순위 |
| 이전 말씀자료 | 톤·표현 학습용 (직접 인용 안 함) | 3순위 |
| 참석자 약력 | 1단 호명·3단 예우 정밀화 | 4순위 |
| 기타 | 본문 컨텍스트로만 활용 | 5순위 |

### 컨텍스트 관리
- 최대 자료 수: 10개
- 총 컨텍스트 토큰: AI 모델 한도의 60% 이내
- 초과 시: 우선순위에 따라 절단 또는 사용자에게 우선순위 지정 요청

## 화면 3 (생성 결과 뷰어)

### 표시 요소
- 생성된 초안 본문 (단계 라벨 표시)
- 분량 검증 (목표 ±10%)
- 가드레일 검증 결과 (10개 항목 ✓/✗)
- 페르소나 일치도
- 빠른 액션: 재생성 / 복사 / 편집 진입

### 단계 라벨 표시 예시
```
[1단 호명·인사]
존경하는 ○○○ 의원님...

[2단 행사 의의]
오늘 「○○○」을 맞이하여...
```
