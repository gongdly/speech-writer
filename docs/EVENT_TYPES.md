# 8가지 행사 유형별 작성 가이드

## 행사 유형 매트릭스

| 유형 | 적용 구조 | 예상 일치율 | 특징 |
|---|---|---|---|
| 축사 | 6단 (표준) | 77.8% | 외부 행사 발화, 참석자 호명 + 정책 사례 |
| 기념사 | 6단 (강력) | 78.7% | 역사적 회고 + 유공자 예우 강조 |
| 신년사 | 6단 (격려↑) | (검증 표본 부족) | 국민 격려·시대 인식이 본문 핵심 |
| 격려사 | 6단 (표준) | 77.3% | 내부 직원·관계자 격려 톤 |
| 환영사 | 6단 (호명↑) | (표본 부족) | 참석자 환영이 1·2단 핵심 |
| 개회사 | 6단 (의의↑) | (표본 부족) | 행사 개시 의의 강조 |
| 이임사 | 6단 (감사↑) | (표본 부족) | 재임 회고 + 감사 표명 |
| **서면축사** | **4단 (별도)** | **33~60%** | **인쇄 배포용, 약식 + 서명 형식** |

## 유형별 작성 가이드

### 1. 축사 (표준 6단)

**핵심**: 외부 행사 주최 측 입장에서 보내는 격려·축하 발화.

**1단 패턴**:
```
존경하는 [주요 외빈 직급순]을 비롯한 내외 귀빈 여러분, 반갑습니다.
[발화자 직책] [이름]입니다.
```

**3단 예우 패턴**:
```
이 자리를 빛내주신 [○○○ 의원님]께서는 [관련 활동]에 깊은 관심을 기울여 주셨고,
[○○○ 대표님]께서는 [관련 헌신]을 위해 노력해 주셨습니다.
또한 [관련 업무 종사자]께도 깊은 감사의 말씀을 드립니다.
```

**4단 정책 사례 패턴**:
```
정부는 「[행사 주제]」를 통해 다음과 같이 [3가지 약속/노력]을 드리고자 합니다.

첫째, [정책 1].
또한, [정책 2].
무엇보다도, [정책 3].
```

**6단 마무리 패턴**:
```
다시 한번 「[행사명]」의 [축하 표현]을 진심으로 드리며,
이 자리에 함께해 주신 모든 분들의 [건강·행복·번영]을 기원합니다.
감사합니다.
```

### 2. 기념사 (6단 강력)

**핵심**: 역사적·연속적 의미가 있는 기념일 행사. 「과거 회고 + 현재 인식 + 미래 약속」 3박자가 명확.

**축사와의 차이**:
- 2단에 **역사적 회고** 추가 (「○○년 동안」, 「○○주년을 맞아」)
- 3단에 **유공자 예우** 강조 (정부포상 언급)
- 4단 정책 사례에 **연속성** 강조 (「우리는 이제 새로운 ○년을 준비」)
- 6단에 **발전 기원** 정형구 (「○○의 무궁한 발전을 기원」)

**2단 역사적 회고 패턴**:
```
오늘 「제○회 ○○의 날」을 맞이하여 그동안 우리가 걸어온 길을 되돌아보며
새로운 도약을 다짐하는 뜻깊은 자리입니다.
[지난 ○○년의 성과·역사] (구체 통계·사례 인용)
```

### 3. 신년사 (격려 비중↑)

**핵심**: 새해 첫 인사. 격려 톤이 강하고 구체적 정책 사례보다 시대 인식·의지 표명이 중심.

**구조 변형**:
- 1·2·3단 격려 비중 60% (일반 6단의 30~40%와 대비)
- 4단 정책 사례 비중 축소
- 5단 「올 한 해」 키워드 비중↑

**1단 패턴**:
```
[부처 명] 가족 여러분, 그리고 국민 여러분, 안녕하십니까.
[발화자 직책] [이름]입니다.
[새해 인사]
```

### 4. 격려사 (6단 표준 + 내부 청중)

**핵심**: 내부 직원·관계자를 격려하는 발화. 외부 청중 없음.

**축사와의 차이**:
- 1단 호명이 「○○ 가족 여러분」 등 내부 호칭
- 3단 예우가 「오늘 표창을 받으신 ○○분」 등 내부 유공자
- 4단이 정책 약속이 아니라 **앞으로의 다짐·당부** 중심

### 5. 환영사 (호명 비중↑)

**핵심**: 외부에서 오신 손님을 맞이하는 발화. 1단 호명·환영이 본문 30% 이상.

**구조 변형**:
- 1단 길이 평소의 2~3배 (참석자 일일이 호명)
- 2단에 **방문 환영 의의** 강조

### 6. 개회사 (의의 비중↑)

**핵심**: 행사 개시 선언. 2단 행사 의의가 본문 핵심.

**구조 변형**:
- 2단이 본문의 30~40%
- 4단 정책 사례 비중 축소

### 7. 이임사 (감사 비중↑)

**핵심**: 재임 종료 발화. 회고와 감사가 중심.

**구조 변형**:
- 2단에 **재임 회고** (구체 사건·성과 회상)
- 5단 가치관·당부에 「후임자에게」 메시지 추가
- 6단에 **재임 동안 감사** 정형구

### 8. 서면축사 (4단 별도 구조)

**핵심**: 인쇄·배포용. 직접 발화하지 않고 행사장에 인쇄물로 배부.

**구조** (4단 구조 사용):
1. 약식 인사 (1단락)
2. 행사 의의·시대 배경 (2~3단락)
3. 정부 의지·정책 방향 (1~2단락)
4. 기대·서명 (일자·직책·이름)

**절대 사용하지 않을 것**:
- 「존경하는 ○○○ 의원님」 직급 서열 호명 (구두 발화 정형구)
- 「반갑습니다」 (직접 발화 표현)
- 「다시 한번 ~을 축하드리며」 (구두 마무리 정형구)

**대신 사용할 것**:
- 「내외 귀빈 여러분께 환영과 감사의 인사를 드립니다」
- 본문에 정책 의지를 풍부하게 풀어쓰기
- 마무리는 「감사합니다」 → 일자 + 직책 + 이름 서명

## 청중별 톤 조정

| 청중 | 한자어 비율 | 격식 | 비고 |
|---|---|---|---|
| 일반 시민 | 30% 이하 | 보통 | 쉬운 말 우선 |
| 공무원 | 40~50% | 격식 높음 | 정책 용어 빈출 |
| 전문가·학계 | 50% | 격식 높음 | 전문 용어 허용 |
| 학생 | 20% 이하 | 보통 | 친근감 있는 표현 |
| 유공자 | 40% | 격식 매우 높음 | 예우 표현 빈출 |
| 외빈 | 30% | 격식 매우 높음 | 외교 의례 |

## 분량별 행사 유형 매칭

| 분량 | 적합 행사 |
|---|---|
| 매우 짧게 (~600자) | 영상 축사, 짧은 환영사, 서면축사 |
| 짧게 (~900자) | 일반 축사, 격려사 (간단) |
| 표준 (~1,500자) | 일반 축사, 기념사, 격려사 (표준) |
| 길게 (~2,400자) | 격식 행사 축사, 취임사 (단일 분야) |
| 매우 길게 (~3,500자) | 신년사, 중요 기념사 (3·1절·광복절급) |
