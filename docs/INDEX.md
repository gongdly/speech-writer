# 말씀자료 AI 작성기 — 개발 착수 자료 패키지

## 사용 방법

Claude Code에서 새 프로젝트 시작 후, 이 `dev_kit/` 디렉토리 전체를 프로젝트 루트의 `docs/`로 복사하거나 첨부해 주세요. Claude Code가 모든 의사결정·구조·규칙을 정확히 이해한 채로 코딩을 시작할 수 있습니다.

## 권장 읽는 순서

| 순서 | 파일 | 분량 | 우선도 |
|---|---|---|---|
| 1 | `PROJECT.md` | 짧음 | ★★★ 필수 (전체 그림) |
| 2 | `ROADMAP.md` | 보통 | ★★★ 필수 (작업 순서) |
| 3 | `TECH_STACK.md` | 보통 | ★★★ 필수 (기술 결정) |
| 4 | `SPEC.md` | 보통 | ★★ 권장 (화면 명세) |
| 5 | `STRUCTURE_RULES.md` | 짧음 | ★★ 권장 (6단 구조·가드레일) |
| 6 | `EVENT_TYPES.md` | 보통 | ★★ 권장 (8개 행사 유형) |
| 7 | `PROMPT_DESIGN.md` | 보통 | ★ 작업 시 (프롬프트 작성 시점) |
| 8 | `DATA_SOURCES.md` | 짧음 | ★ 작업 시 (데이터 활용 시점) |

## 데이터 자산

- `data/speech.xml` — 정책브리핑 연설문 RSS 50건
- `data/items_classified.json` — 행사 유형·발화자 분류 결과
- `data/tagging_results.json` — 6단 태깅 결과

## 핵심 결정 요약 (한눈에)

| 항목 | 결정 |
|---|---|
| 출력 형식 (MVP) | **MD 단일** |
| 출력 형식 (v2) | HWPX 추가 (PoC 후) |
| 행사 유형 | 8종 (서면축사 별도) |
| 분량 옵션 | 5단계 + 사용자 지정 |
| 6단 구조 | 호명 → 의의 → 예우/비전 → 정책 → 당부 → 마무리 |

| 기술 스택 | **진료후 패턴 그대로** (Next.js 15 + Cloudflare + Claude API) |
| 개발 방식 | 빅보스님 + Claude Code |
